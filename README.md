HTML & CSS Assignment

Overview
A static multi-section layout demonstrating HTML5 semantic structure, Flexbox, CSS Grid, the Box Model, and positioning techniques.

Features Implemented
* **Flexbox Layout:** Navbar horizontal alignment and flexible feature cards using `flex-wrap`.
* **CSS Grid:** A responsive 6-item grid utilizing `repeat(auto-fit, minmax(150px, 1fr))`.
* **Box Model:** Strategic application of `margin` and `padding` for spacing.
* **Positioning:** Clear demonstration of `absolute` positioning nested inside a `relative` parent.
* **Responsive Design:** Mobile-friendly layouts powered by media queries (`max-width: 768px`).
